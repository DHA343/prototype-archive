# ボール

## 共通シーン

- `experiments/ball/ball.tscn` が描画、円形の当たり判定、重力と反射を持つ。ピンボールや特定の盤面サイズへ依存させない。
- 重力・反発係数・色・色強度はルートに公開し、配置先のインスタンスで上書きできる。色強度はリニアRGBへ掛け、HDRを保持する。色の変更はエディターにも反映する。
- 自動物理更新では最大1/240秒ずつ進める。外部で更新を管理する利用先は自動更新を止め、stepを呼ぶ。二重に更新しない。
- 移動はCharacterBody2Dの経路検査で扱い、法線方向のみ反発係数を適用する。8回の接触でも解消できない場合は残りの移動を破棄する。

## ピンボールでの利用

- `experiments/pinball/ball.tscn` と同名スクリプトで共通ボールを継承する。落下復帰、フリッパーとバンパーへの特殊な応答、打球速度はピンボール側へ置く。
- Tableがフリッパーと球を同じ刻みで進めるため、ピンボールの球は自動物理更新を止める。
- 球本体は共通ボールが描く。盤面上の影と接触粒子・軌跡は描画順を保つためTableが扱う。
