# ミサイルの追尾

## 構成

- 採用方式は、目標の横へずらした狙い点を追尾し、希望方向へ断続的な角度補正を加える方式。
- `experiments/missiles/missile.tscn` のルートNode2Dと `missile.gd` で飛行・横ずれ・不安定さ・命中・寿命を扱う。見た目は子ノードVisualsが所有し、飛行処理は分割しない。
- ミサイルには巡航速度上限・加速度・追尾・不安定さ・寿命を設定する。Launcherは発射数・発射間隔・発射方向のばらつきに加え、初速・直進時間・希望速度の立ち上げ時間を所有し、発射時に位置・方向・目標・seed・初速を渡す。
- Arenaは目標・背景・比較表示を、プレビューは操作と枠配置を担当する。排気・煙・軌跡・着弾粒子の生成や更新はArenaへ依存させない。
- ミサイルの状態はSTRAIGHTとHOMINGの2種類とする。直進は指定方向を維持し、追尾は狙い点・不安定さ・希望方向を計算する。速度への応答と加速度制御は両状態で共通にする。更新内で完結する一時値はメンバーへ保持しない。

## 狙い点と移動

- ミサイルは時間経過だけでは追尾へ切り替わらない。Launcherが弾ごとの経過時間を管理し、物理更新単位でstart_homingとdesired_speedを指示する。巡航速度の指示を終えた弾は制御対象から外す。
- 目標は毎物理更新で最新位置を参照する。現在のミサイル位置から目標へ向かう方向に垂直な左右へ、仮の狙い点をずらす。
- 発射時に横ずれなしの確率を判定し、それ以外は最大量に対する符号付き倍率を-1〜+1から一様抽選する。左右と強さは飛行中維持し、目標の移動時に再抽選しない。
- Zero Distance以下で横ずれを0にする。Zero DistanceからFade Distanceまでの距離比のPower乗を横ずれに適用する。Zero Distanceの初期値は0で従来の挙動を維持する。Fade DistanceがZero Distance以下なら減衰区間を持たず、Zero Distance以下で0、それより外では最大量とする。Powerは設定可能で、1なら線形、2なら従来の二乗。1より大きいと目標距離より速く横ずれが縮み、目標方向へ収束する。Zero Distanceが0でPowerが1以下の場合、同じ収束特性にはならない。固定の進入角や未来の目標位置は指定しない。
- 狙い点へ向く方向に不安定さの角度補正を加え、外部から受け取った希望速度と組み合わせて希望速度ベクトルを求める。実速度は応答時間と加速度上限を通して変え、更新前後の平均速度で位置を積分する。
- 直進中は目標がなくても飛行できる。追尾中の目標消失、命中、寿命到達で飛行を終了する。
- fly_straightで方向を指定し、start_homingで目標を指定する。希望速度を下げても実速度は瞬時に切り詰めず、加速度制限に従って減速する。
- 位置へ直接ノイズを加えない。急な目標移動でも実速度を瞬時に切り替えず、旋回中の減速と向きが揃った後の再加速を同じ速度制御で扱う。

## 追尾中の速度

- 外部のdesired_speedは速度指示として維持し、ミサイル内で追尾中の希望速度を下げる。直進中は旋回による減速を適用しない。目標までの距離による速度変更は行わない。
- 実速度方向と、不安定さを適用した希望方向の角度差に応じて指示速度を下げる。角度差0で100%、Turn Angle以上でTurn Speedの割合となる。実速度0のときは方向がないため旋回減速を適用しない。Turn Speedを100%にすると旋回減速を無効にできる。
- 希望速度への追従は既存の応答時間と加速度上限を通す。実速度を瞬時に切り詰めず、方向が揃うと再加速する。

## 不安定さ

- 不安定さは追尾中に評価する操舵角の補正であり、ミサイルの動作状態ではない。採用ミサイルに段階を表すenumや立ち上がり・復帰の補間は持たせない。
- 1周期を休止と保持の時間軸で表す。休止時間・符号付き角度・保持時間を周期ごとに抽選し、休止中は0、保持中は抽選角度をそのまま使う。初回も休止から始める。
- 周期内の経過時間から補正量を求める。周期の境界で余った時間は次へ引き継ぎ、ゼロ長周期を通過する。保持・休止がどちらも全範囲0なら補正しない。Min / Maxの大小は並べ替えて扱う。
- 左右交互や最低角度は強制しない。同じ側が続くこと、小さい角度、ほぼ0の角度も許容する。
- 希望方向の角度は即座に切り替えるが、実際の動きは加速度制御を通す。角度補正用の立ち上がり時間・復帰時間・補間切り替え設定は設けない。
- 追尾開始時に補正全体の影響を立ち上げる時間と、目標手前で補正を弱める距離は残す。これは保持する角度を補間する処理とは別の影響度の制御。
- 横ずれと不安定さはミサイルごとに独立した乱数列を使う。目標更新や表示更新で周期や乱数をリセットしない。
- 設定と内部名はInstabilityで統一し、実行時の異常を表すerrorと区別する。

## 見た目

- 本体・排気・煙・軌跡・着弾演出はmissile.tscn内のVisuals（visuals.tscn / visuals.gd）で完結する。通常のNode2Dの下へ生成するだけで表示できる。
- 排気・煙・着弾粒子はVisualsのGPUParticles2Dで更新・描画する。発生位置・寿命・速度・サイズの抽選は従来と同じ距離基準・乱数順でCPUから渡し、生成後の粒子をGDScriptの配列で管理しない。本体と軌跡線はVisualsが描く。
- 粒子と軌跡はワールド位置で保持し、本体の移動・回転に引きずられないようにする。速度も親の座標系から変換する。描画だけをピクセル単位に丸め、飛行位置は丸めない。粒子はカスタムprocessシェーダーで抵抗・重力・寿命を計算し、canvasシェーダーで1pxの火花、1〜3pxの煙、色・透明度・光彩を再現する。
- GPU粒子もプレビューの一時停止と再開へ追従させる。発生後のシミュレーションは60Hz。飛行終了後のVisualsは従来通り1.2秒残し、最長0.9秒の粒子と軌跡が消えてから解放する。
- 見た目用の乱数は追尾計算から分離する。粒子数や表示の切り替えで飛行軌道を変更しない。
- 飛行終了時は本体の表示を止め、Visualsをミサイルの親へ移す。残った煙・着弾粒子・軌跡が寿命を終えたらVisuals自身を解放する。独立した飛行状態は追加しない。
- 比較用の旧1〜3も同じVisualsを使うが、飛行計算と発射時の乱数消費順は保持する。

## 比較と可視化

- `preview.tscn` は現行ミサイルだけを640×360固定で描画し、Nearestで縦横比を保って画面へ拡大する。画面比率による余白を許容し、ウィンドウサイズで描画範囲を変えない。通常のLauncherを使う。旧方式は検証用の `comparison/` に分離し、通常プレビューから読み込まない。
- 検証用Launcherは従来の発射方向とseedの組を維持する。旧方式の設定・補間処理は検証用として独立しており、現行ミサイルの調整を自動反映しない。
- Cで実位置・狙い点・目標位置と補正後の希望方向の表示を切り替える。
- ミサイルは直前の追尾計算の状態だけを返し、表示用点列・色・HOLD / RESTの表示名はプレビュー側で組み立てる。移動後の位置から飛行計算時点の情報を作り直さない。
- 生存中の最も古い弾を1発選び、飛行終了後は次の弾へ切り替える。
- 停止中の目標変更では狙い点と希望方向のみを更新し、実位置・実速度・寿命・周期の経過時間・乱数は進めない。Launcherの指示時刻とVisualsの粒子・軌跡も停止する。

## 検証

- 設定値・操作・実行手順は[ミサイル実験](../../experiments/missiles/README.md)を参照する。
- 30/60/120Hz、静止・移動・途中の目標位置変更について、4方式それぞれ180条件で速度・加速度上限、最新目標の参照、速度積分と着弾を確認する。任意条件での命中保証とはしない。
- ミサイル単体で目標なしの直進、外部指示による追尾、希望速度低下時の加速度上限、Arenaなしの見た目、終了後の演出寿命を検証する。
- 速度制御は距離によらない速度指示、旋回角の対称性・上限、外部の低速・停止指示、直進への非適用、加速度上限を検証する。
- 不安定さは周期の時刻、補間を含まない角度、ゼロ時間、乱数の再現性と独立性、強度0、回転に対する一致を検証する。
- 可視化ON / OFFで飛行・乱数が変わらないこと、停止中の目標変更で時間が進まないことを検証する。
- 削除した方式や変更前の測定値を現在の性能として引用しない。READMEには現行設定・測定条件を添えて直接追尾との比較値を記録する。計測は最小構成、共通の加速度制御、現行方式を分け、演出の負荷を含めない。

## 演出の負荷

- 追尾だけのCPU計測を、ミサイル全体の負荷と解釈しない。Visualsの粒子更新と描画コマンド生成、着弾後の残存演出、生成・解放を含めて確認する。
- 置換前の演出込みデバッグ計測では、粒子をGDScriptで更新・個別描画するCPU負荷が支配的だったためGPUParticles2Dへ移した。置換前の計測値を現在の性能として扱わない。本体・軌跡・発生処理はCPUへ残る。置換後との比較・実行条件・計測用シーンは[ミサイル実験](../../experiments/missiles/README.md)を参照する。
- 同じ演出を使っても、追尾方式による速度・飛行時間・着弾頻度の差で粒子数が変わる。追尾単独と演出込みの比較は目的を分けて解釈する。
