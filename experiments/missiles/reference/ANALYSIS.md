# 参考動画の軌道分析

## 素材と方法

- 対象は [BeamManPの動画](https://x.com/BeamManP/status/2103139248518082670)。公開メディアのMP4を取得し、ffprobeで1728×648、60fps、12秒、720フレームと確認した。
- 元動画と全フレームはプロジェクト内の `_temp/missile_reference/` に保存した。ブラウザー上の数枚のスクリーンショットだけで判断した以前の実装は、この分析の根拠に含めない。
- 検出用画像は576×216へ縮小した。これは解析用の座標系であり、元の内部描画解像度を断定するものではない。各レーンは192px幅。
- 最初に後方右へ出てから左上へ戻る先行弾を対象に、白熱している発光域を追跡した。孤立した白い火花へ追跡が移るケースがあったため、連続フレームを目視確認して対応点を補正した。
- 発光域の重心は弾本体の正確な座標ではなく、残光や複数粒子の影響を受ける概算。特に発射直後と命中付近は精度が落ちる。重なりが強い区間から正確な加速度を断定しない。
- [追跡フレーム](tracked_frames.png)の黄色い丸が対応点。[CSV](first_shot.csv)にフレーム番号・時刻・座標を保存した。CSVのフレームは0始まりで、抽出PNGの番号は1始まり。

## 観測

| 時刻 | HERMITEの発光域重心 | SPIRALの発光域重心 |
| --- | --- | --- |
| 0.83秒 | (114.6, 152.0) | (113.4, 151.7) |
| 1.00秒 | (134.7, 161.6) | (137.8, 162.1) |
| 1.17秒 | (148.5, 168.2) | (148.3, 166.9) |
| 1.33秒 | (160.8, 174.2) | (159.5, 172.5) |
| 1.50秒 | (143.2, 163.3) | (147.5, 156.2) |
| 1.67秒 | (116.3, 144.4) | (108.9, 150.4) |
| 1.83秒 | (80.7, 115.7) | (90.2, 113.1) |
| 2.00秒 | (62.0, 94.0) | (57.9, 100.0) |

- 射出区間の両方式はほぼ重なり、帰還区間では共通する大きなS字の経路に小さなずれが重なる。
- 1.50〜2.00秒の対応点の差を局所的な進行方向へ分解すると、主な差は横方向。横ずれは概ね8〜10px程度で、符号が交互に変わる。時間間隔から変動の周期は約0.3秒前後と推定するが、サブフレーム精度の周波数測定ではない。
- HERMITEの対応点間の平均移動は、1.00〜1.33秒で約87px/s、1.50〜1.83秒で約236px/s。発光域の概算なので弾の厳密な速度ではないが、帰還中の方が速いことは読み取れる。
- SPIRALが独立した大きな円や楕円を追いかけ続ける軌道は、この対応区間とは一致しない。

## 現在の実装との関係

- 観測・画像・CSVは参考動画の名称を維持する。現在の実験は通常の加速度追尾と、保持・復帰・休止を持つ操舵誤差の比較に整理した。
- 参考動画の数式を特定したものではない。現在の設定と動作は[実験README](../README.md)を参照する。
