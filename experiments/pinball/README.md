# ピンボール実験

## 盤面の調整

- **`table.tscn` をGodotの2Dエディタで開いて編集する。実行は不要。** 移動・複製・削除・Undo/Redo・保存はGodot標準の操作を使う。保存したシーンを `preview.tscn` がそのまま参照する。
- 移動時の吸着には2Dエディタの「グリッドスナップ」を使い、スナップ設定の間隔を8×8pxにする。4／16pxへ変更してもよい。InspectorのTable → Editor → Grid Sizeは補助ボタンで使う間隔で、標準スナップ設定から独立している。同じ値に揃えて使う。
- `Walls` 内の壁はPath2D。選択すると標準のパス編集で頂点の追加・移動・削除とベジェハンドルを操作できる。ハンドルを伸ばすと曲線、ゼロにすると直線になる。Curve2Dを別の壁と共有して編集したくない場合は「ユニーク化」する。
- `LeftFlipper` / `RightFlipper` を選び、InspectorでLength、Rest Angle、Raised Angle、Rise Speed、Return Speedを変更する。2Dエディタの回転操作もRest Angleへ反映する。長さを変更すると丸い両端を保って形状と衝突が更新される。
- Shot AnglesとShot StrengthsのRoot／Middle／Tipが根元0%・中央50%・先端100%に対応する。区間ごとに線形補間する。角度は外向きが負、真上が0、中央向きが正。強度は球の打球速度への倍率で、球の速度上限を超えない。選択中の3本の矢印で方向と強度、破線で振上位置を確認する。これらの補助表示は実行時には出さない。
- `Bumpers` 内のバンパーを移動し、InspectorでRadius・Kick Speedを変更する。
- 各部品のEditor欄に「位置をグリッドに揃える」「対称側へ反映 / 作成」を用意する。壁には「制御点をグリッドに揃える」もある。対称反映はx=320を軸とし、Mirror Pathに相手があれば更新し、未指定なら相手を作る。天井のMirror Pathが`.`の場合は、左側の制御点から右側を揃える。反映はボタンを押したときだけ行うので個別編集もできる。
- TableのEditor欄から直線の壁・曲線の壁・バンパーを追加できる。補助ボタンの操作もGodot標準のUndo/Redoへ登録する。部品の追加・複製・削除は標準のシーンツリーでも行える。
- Ctrl+Sで `table.tscn` を保存し、動きを確認するときだけ `preview.tscn` をF6で実行する。球の設定はBallのInspectorで編集する。

## 通常のプレビュー

- `preview.tscn` をF6で実行する。
- Spaceで左右のフリッパーが同時に、下向き20度から水平まで上がる。離すと戻る。
- 打球方向は根元の外側16度から、長さの25%で真上を通って先端の中央寄り48度まで連続的に変わる。左右は対称。外側の根元から中央の先端へ球が滑るほど中央へ打ち出す。押してから100ms以内の最初の有効な接触で550px/sの打球を出し、同じ押下で重ねて加速しない。押し続けた後と戻るときは受動的な反発だけにする。
- 下部へ落ちてきた球が「今押した場合」に有効な打球となるとき、現在の球の中心から打球方向へ白い直線を表示する。打球後の落下軌道は描かない。Tableの `show_shot_guide` で表示を切り替えられる。扇状表示は置かない。
- Rでボールを左フリッパーの外寄りの上方へ戻す。下へ落ちた場合も自動で同じ位置へ戻る。
- 初期配置はボール1個、バンパー6個、壁と左右のフリッパー。バンパーは上部左右・中央左右・下部の壁際へ置き、中央軸x=320に対して各段を左右対称に揃える。得点・球数・終了条件は持たない。
- ボールは直径12px。描画と当たり判定は同じ半径を使う。フリッパーの上面も衝突輪郭と一致させ、球の影はその背面に描く。
- Ballは[共通ボール](../ball/README.md)のシーンとスクリプトを継承する。InspectorのMotionで `gravity` と `restitution`、Appearanceで `color` と `intensity` を調整できる。1を超えるHDRの明るさも使える。球の設定は盤面の配色と独立して保持する。
- バンパーへの衝突1回につき、中心から紫のミサイルを1発出す。盤面中央上部のTargetを追尾し、命中時に目標が発光する。バンパーは12msで約12%膨らみ、110msで元へ戻る。膨らむのは描画のみで、当たり判定を拡縮しない。
- ミサイルは `experiments/missiles/missile.tscn` を使い、ピンボール側で紫色を指定する。発射直後から追尾し、初速80px/sから既存の加速度制御で巡航速度へ移行する。飛行用の乱数列は盤面の火花から分離する。
- ボールの重力・速度上限・反発係数はBallのMotion、基準の打球速度はBallのFlipperで調整する。フリッパーの回転速度と位置別強度、バンパーの最低離脱速度はそれぞれのノードのInspectorで変更する。
- ピンボール側のボールは重力630px/s²、反発係数0.3、速度上限600px/s、打球速度550px/s。バンパーは反発後の法線方向速度が480px/s未満のときだけ補い、毎回一定の速度を加算しない。640×360に合わせ、共通ボールを変更せずピンボール側で調整する。
- ボールとフリッパーはTableが最大1/240秒の刻みで同時に更新する。球の移動経路と、回転したフリッパーとの重なりを確認する。中央のフリッパー間は落下口として空けている。
- 配置と設定は `table.tscn` の通常ノードとCurve2Dへ保存する。各部品の `@tool` スクリプトが表示と衝突形状を更新する。表示サイズは `preview.gd` で扱う。
- 左右の縦壁は盤面の上下まで通す。枠は単色の太いラインで構成し、天井と下部のガイドは滑らかなベジェ曲線にする。フリッパーは丸い根元と先端を接線でつなぎ、描画と衝突で輪郭を共有する。
- 描画は640×360の固定解像度。盤面も16:9へ再配置し、縦につぶさず寸法と物理座標を合わせる。最近傍で整数倍に拡大し、720pは2倍、1080pは3倍、1440pは4倍、4Kは6倍。その他の画面では整数倍の残りを余白にし、640×360未満では縮小して全体を収める。4倍MSAAとラインのアンチエイリアスを使い、枠とフリッパーの頂点は丸めない。火花や軌跡はドットで描く。
- 物理は真上から見た2Dのまま、SubViewportのcanvas_transformで表示だけを浅い斜め視点の比率へ変換する。床は24pxの暗いグレーのチェック柄。バンパーは影・縁・模様のないライトグレーの円、フリッパーは同色の平面塗り、枠はグレーにする。ミサイルと目標は紫。画面下部の操作説明も表示しない。
- 配色は `styles.gd` の `MONOCHROME`。旧配色の数字キーによる切り替えは削除した。
- `main` と同じポストプロセスシーンを参照する。
- 配置の参考と衝突方式の設計は [ピンボールの設計](../../docs/design/pinball.md) を参照する。
- `godot --headless --path . --script res://experiments/pinball/tests/physics_test.gd` で、30/60/120Hzの高速衝突・反発・左右フリッパーの根元/中央/先端・落下復帰を検証する。
- `tests/aim_test.gd` は予測による実物の変更がないこと、左右18通りの進入位置・速度で予測方向と実際の打球方向が2度以内で一致すること、押し続けた状態と打球可能時間外には線を出さないことを検証する。左右の休止中のフリッパー上を実際に滑らせ、線が外向きから真上を通って中央向きへ連続的に変わることも確認する。
- `tests/layout_test.gd` は30/60/120Hzで20秒ずつ、反応操作と一定周期の操作を行い、バンパー衝突・枠内の維持・速度上限を確認する。実画面用の `tests/playtest.gd` は実行中のTableを渡して使い、操作終了時に入力を解除する。ゲーム本体からは読み込まない。
- `tests/preview_test.gd` は640×360の内部解像度と、画面サイズに応じた整数倍拡大・縮小・余白、バンパーの対称配置を確認する。
- `tests/authoring_test.gd` はCurve2Dと形状の更新、標準シーン保存からの再読込、打球角度・強度の補間と上限、変更した配置での予測と打球の一致を確認する。
- `tests/playtest_results.json` は縦壁・長いフリッパーへの変更前の配置比較を記録したもので、現在の形状の測定値ではない。
